FieldExampleNotes

decoded "рф" Unicode form of an internationalized domain, decoded from punycode (RFC 3492); null for ASCII TLDs

How it stays fresh

The update.yml workflow runs monthly, fetches tlds-alpha-by-domain.txt and the IANA root zone database, regenerates the JSON and commits only when the data actually changed. GitHub Pages serves the result. No server to run.

Data source and accuracy

The record set is the IANA TLD list — 1,436 delegated TLDs. The type and script come from the same IANA root zone database, which is the authoritative registry: 309 country-code, 1,126 generic, 1 special-use (arpa). The 151 internationalized (IDN) domains carry their punycode label and the decoded Unicode form, decoded with a RFC 3492 decoder verified against the IANA root database's own display names.

Limits, stated plainly

  • The alpha list only contains delegated TLDs; the root database also lists 5 "eligible" entries that are not yet in the DNS and are therefore excluded here.
  • No registry or sponsor data is included — the root database's manager column is not carried over.
  • Type is only as fresh as IANA's root database page; a very new TLD may briefly carry the fallback classification until the page is updated.
  • The root database is an HTML table, so a redesign of the page would break the type enrichment — the build then falls back to a structural classification and logs a warning.
